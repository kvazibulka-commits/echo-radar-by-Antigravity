# Скилы ЭХО

Проектные скилы для агентов: концепция, дизайн, разработка и стандарты качества.
Лежат в репозитории как источник истины и устанавливаются в
`%USERPROFILE%\.agents\skills\` командой:

```bat
python tools/install_skills.py
```

После установки агент видит их в каталоге скилов (в некоторых сборках харнесса —
в новой сессии). Проверить: попросить агента «загрузи скил echo-visual-design».

## Состав

| Скил | Когда загружается | О чём |
|---|---|---|
| `echo-product-concept` | продукт, тексты, названия, границы фич | философия, словарь, тон, сценарий вечера |
| `echo-visual-design` | UI, вёрстка, цвет, анимации, скриншоты | токены, типографика, сонар, дека, компоненты, доступность |
| `echo-engineering` | код сервера/шаблонов/Android, API, деплой | архитектура, контракт, авторизация, БД, сборка |
| `echo-quality` | ревью, коммит, релиз, спор о стандартах | безопасность, стиль, бюджеты, DoD, анти-паттерны |

Читать в связке: концепция задаёт «зачем», дизайн — «как выглядит», разработка —
«как устроено», качество — «когда готово».

## Правила поддержки

1. Меняешь дизайн-токены — обнови `echo-visual-design` и оба `:root`.
2. Меняешь API или авторизацию — обнови `echo-engineering` и `README.md`.
3. Меняешь продуктовый словарь — обнови `echo-product-concept`.
4. Новый анти-паттерн из реального бага — добавь строку в `echo-quality`.
5. Скилы не дублируют код: источник истины — файлы проекта, скил описывает
   инварианты и порядок действий.
6. Держи `SKILL.md` компактным (до ~300 строк): длинные детали — в коде и README.
