# ЭХО — дизайн-система и визуальный язык

## Когда использовать

- Меняешь цвет, шрифт, отступ, радиус, тень, иконку, анимацию.
- Верстаешь новый экран, карточку, шторку, панель, состояние загрузки/ошибки.
- Проверяешь скриншот или мобильную вёрстку 390 px.
- Согласуешь Compose-экран Android с веб-версией.

## Источники истины (читать до правок)

| Что | Где |
|---|---|
| Токены Android | `app/src/main/java/ru/echo/radar/MainActivity.kt`, объект `EchoTokens` |
| Токены мобильного веба | `templates/pwa.html`, блок `:root` |
| Токены пульта | `templates/dashboard.html`, блок `:root` |
| Эталонные скриншоты | `docs/screenshots/*.png` |
| Живая проверка | `python tools/cdp_shot.py --url http://127.0.0.1:8080/app --out shot.png --mobile` |

Правило: **сначала токен, потом значение.** Если нужного цвета нет — добавляй токен
в оба места (Compose + оба `:root`) и объясняй роль, а не вставляй hex по месту.

## Палитра

### Два уровня неона

- **Сигнальный циан `#00F0FF`** — только для «живого»: свой маяк, активный сигнал,
  игла, ключевые акценты на деке. Максимальная яркость, минимум площади.
- **Небесный `#38BDF8`** — рабочий акцент интерфейса: ссылки, заголовки карточек,
  кнопки, иконки навигации. Читается мягче и не утомляет на больших экранах.

Не путай их: если элемент просто «важный» — `#38BDF8`; если «звучит прямо сейчас» —
`#00F0FF`.

### Токены

| Токен | Hex | Роль |
|---|---|---|
| Background | `#07090E` (app) / `#070A12` (web) | Ночное небо, фон всех экранов |
| Surface | `#0D121B` (app) / `#0F172A` (web) | Базовые панели, шторки |
| SurfaceElevated | `#151E2A` | Диалоги, поднятые карточки, bottom sheet |
| Divider / line | `#26313E` / `#1E293B` | Границы, разделители, сетка сонара |
| Line strong | `#334155` | Границы полей ввода и чипов |
| TextPrimary | `#F2F5F7` (app) / `#E2E8F0` (web) | Заголовки, названия треков |
| TextSecondary | `#85909E` (app) / `#94A3B8` (web) | Подписи, метаданные |
| Dim | `#64748B` | Третичный текст, плейсхолдеры |
| SignalCyan | `#00F0FF` | Живой сигнал, свой маяк, игла |
| SkyBlue | `#38BDF8` | Основной веб-акцент, ссылки, кнопки |
| PurpleResonance | `#A855F7` | Слушатели «вопреки», пост-панк/синти-вайб |
| VinylAmber | `#FFB800` | Винил, тайники, тёплые состояния |
| Gold | `#FFD700` | Синхрон иглы, точка Лагранжа, награда |
| Green | `#34D399` | Успех, «резонанс совпал», онлайн |
| WarningRed | `#FF5533` / `#F87171` | Опасность, заблокированный тайник, офлайн |
| DeepCyan | `#0284C7` | Заливка основных кнопок, градиенты |

Цвет — не единственный носитель смысла. К призрачному сигналу добавляй пунктир и
подпись, к синхрону — золотое кольцо, к тайнику — ромб. Иначе дальтоник не отличит.

## Типографика

- **Шрифт:** системный стек (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto`).
  В Compose — `FontFamily.Default`; только технические подписи — `Monospace`.
- **Логотип:** 21–26 sp, вес 900, `letter-spacing` 3–4 sp. Никогда не растягивай
  и не добавляй тень.
- **Заголовок экрана:** 20 sp, Bold, `letter-spacing` 1.5.
- **Заголовок карточки/секции:** 13–17 sp, Bold.
- **Название трека:** 14–15 sp, Bold; всегда `maxLines = 1` + ellipsis.
- **Метаданные и чипы:** 9.5–12 sp; в вебе 10.5–12 px.
- **Технические подписи** (СОНАР, НАСТРОЙКИ, ЗВУКОВОЙ ПАСПОРТ): Monospace,
  CAPS, `letter-spacing` 1–1.5, цвет Dim или Cyan.
- **Строка текста:** не длиннее ~60 символов; `line-height` 1.45–1.55.

Русский текст длиннее английского на 15–25 %. Планируй переносы и ellipsis заранее,
не уменьшай шрифт ниже 12 px ради влезания.

## Пространство и форма

- Базовая сетка **4 / 8**. Отступы: 4, 6, 8, 10, 12, 14, 16, 18, 20, 24.
- Горизонтальные поля экрана: **16–18 dp**; пульт на десктопе — 22 px.
- Радиусы: чипы 6–8, кнопки 10–12, карточки 14–18, диалоги/шторки 22–24, пилюли 999.
- Границы: 1 px `#1E293B`; активное — 1.5 px Cyan.
- Тень: только у поднятых слоёв (`0 10px 40px rgba(56,189,248,.18)`), не у карточек
  в списке — там работает левая акцентная полоса 3 px.
- Внутренние отступы карточек: 12–18; между карточками — 9–12.

## Движение

| Анимация | Длительность | Кривая |
|---|---|---|
| Вращение винила | 1800 мс / оборот (33⅓ RPM) | linear |
| Пульс неона | 2400 мс туда-обратно | FastOutSlowIn |
| Луч сонара | 0.9°/кадр при ~30 fps | linear |
| Переход экрана | 180 мс появление / 140 мс уход | tween + slide 20 px |
| Bottom sheet | 260 мс | cubic-bezier(.16, 1, .3, 1) |
| Тост | 300–320 мс, живёт 3–3.2 с | тот же |
| Пульсация сигнала | ±10 %, период ~840 мс | sin |

Правила:

- Никаких bounce, spring с отскоком, миганий и «конфетти».
- Сонар рисуй не чаще 30 fps и останавливай при скрытой вкладке/неактивном экране.
- Анимация не должна быть единственным индикатором состояния.
- Уважай `prefers-reduced-motion`: оставляй fade, убирай вращение и параллакс.

## Сонар: геометрия и слои

Порядок отрисовки строго снизу вверх:

1. Фон и рассветное свечение (`isDawnMode`, радиальный градиент Gold 0.10 → 0).
2. Кольца `0.3 / 0.55 / 0.78 / 1.0` от `maxR`; внешнее — Cyan 0.22.
   `maxR = min(w, h) * 0.42`, центр — центр canvas.
3. Перекрестие — Divider.
4. Тепловые пятна — радиальный градиент `rgba(251,146,60, α)`, α падает с возрастом.
5. Луч — линейный градиент от прозрачного к Cyan 0.55, ширина 2.4 dp.
6. Сигналы: ореол (α 0.12) → тело (6.5–9 dp) → белое ядро (1.6–3 dp).
   Призрачные — α 0.55 и пунктирное кольцо; синхронизированные — золотое кольцо +5 dp.
7. Тайники — ромбы: заведение 7 dp с белой обводкой, обычный 5.5 dp.
8. Точка Лагранжа — пунктирная окружность 20 dp + подпись с тёмной обводкой.
9. Свой маяк в центре — Cyan 5 dp + кольцо α 0.3.

Зоны на карте: круг радиусом 450–750 м, заливка 0.08; сигналы — ореол 190 м;
капсулы — 110–150 м. Стиль тайлов — тёмная инверсия (`filter: invert + hue-rotate`).

## Дека и винил

- Диск вращается непрерывно, угол не сбрасывается при навигации.
- Пауза сохраняет угол; возобновление продолжает без рывка.
- Тонарм — оверлей; при проигрывании опущен, при паузе приподнят.
- Центральный лейбл — обложка или цвет архетипа; обводка 2 dp.
- Основные действия вокруг диска: play/pause, «синхрон иглы», «волна», «в летопись».
- Не добавляй к деке кнопки «поделиться в соцсетях», «оценить», «комментарии».

## Компоненты

**Карточка сигнала** (`card` в вебе, `Surface` в Compose):

```
[3px цвет] Персона ····················· [призрак]   →
           Артист — Трек
           [Резонанс 88%] [140 BPM] [9A] [Зона] [Встреч 6]
           [▶ Слушать] [🪡 Синхрон] [🌊 Волна] [✦ Отклик]
```

- Высота строки трека — одна строка с ellipsis; персона — тоже.
- Чипы 9.5–10.5 px, фон `rgba(30,41,59,.7)`, рамка `#334155`, значение — bold.
- Кнопки-глифы: 34×30, только символ; текстовая подпись — в `title`/`aria-label`.
- Тап-таргет не меньше 44×44 (в вебе — 44 px, в Compose 48 dp для основных действий).

**Bottom sheet:** ручка 42×4, заголовок Monospace, крестик 20 px, радиусы 22 сверху,
максимум 88vh, скролл внутри. Паспорт сигнала — тот же лист, но с аватаром-диском
68 dp и тремя блоками акустики (резонанс / темп / Camelot).

**Тост:** один на экран, сверху или снизу, 3 секунды, без стека. Ошибка — красная
рамка и символ ⚠, успех — Cyan и символ действия.

**Mini-player:** показывается на всех экранах кроме ДЕКИ; высота ~64 dp, обложка 44,
вращение синхронно с декой.

**Карточка подключения плеера (ДЕКА, пустое состояние):** заголовок 13 sp, пояснение
10.5 sp / 15 sp line-height, две кнопки высотой 38 dp: «Разрешить доступ» (заливка
Cyan, чёрный текст 11 sp) и «Транслировать из Яндекс Музыки» (Surface, рамка SkyBlue,
текст 10.5 sp в две строки). Показывается только пока трек не определён; жанровый
бейдж и «призрачные» метаданные в этом состоянии скрываются.

**Виджет «Сейчас играет»:** карточка 250×90 dp, фон Surface `#0D121B`, радиус 18,
рамка `#1E293B`, padding 14. Строки: «ЭХО · СЕЙЧАС ИГРАЕТ» — 9 sp, Monospace, Dim,
letter-spacing 0.12; трек — 15 sp bold TextPrimary, одна строка с ellipsis; артист —
12 sp SkyBlue; образ — 10 sp italic, цвет архетипа. Тап по виджету открывает ДЕКУ.

## Вёрстка

| Контекст | Правила |
|---|---|
| Телефон 360–430 px | 4 вкладки, шрифт вкладок 11 px, header 44–52 px, safe-area снизу |
| iPad / PWA | те же вкладки, сонар и карта на всю площадь, шторки по центру снизу |
| Пульт ≥ 1080 px | 2 колонки (1.08fr / 0.92fr), KPI в 4 карточки, max-width 1480 |
| Пульт < 1080 px | одна колонка, KPI в 2×2 |

Запрещено: горизонтальный скролл, обрезанные вкладки, текст поверх сонара без
подложки, фиксированные высоты под длинный русский текст.

## Доступность

- Контраст: тело ≥ 4.5:1, крупный текст ≥ 3:1. Проверяй фактически, а не на глаз.
- Не делай статус только цветом: добавляй форму, пунктир, подпись, иконку.
- Все интерактивные элементы доступны с клавиатуры и имеют `aria-label`.
- Уважай системный размер шрифта: интерфейс не должен ломаться при 130–150 %.
- Двигай фокус в шторку при открытии и возвращай обратно при закрытии.

## Чек-лист дизайн-ревью

1. Палитра из токенов, сигнальный циан не размазан по площади.
2. Заголовок/трек/метаданные различаются размером и весом, а не только цветом.
3. Одна строка — ellipsis; никаких обрезанных букв.
4. Тап-таргеты ≥ 44 px, между ними ≥ 6 px.
5. Есть состояния: загрузка, пусто, ошибка, офлайн, призрак.
6. Анимация ≤ 300 мс для UI, винил/сонар — медленные и непрерывные.
7. Скрытая вкладка не жжёт батарею.
8. Тёмная тема без «чёрного на чёрном»: поверхности различимы на 3–5 % яркости.
9. Русский текст проверен в худшем случае (длинное имя артиста, 3 строки послания).
10. Мобильная ширина 390 px проверена скриншотом, а не предположением.
11. Скриншот сделан через `tools/cdp_shot.py`, ошибок JS нет.
12. Новый цвет/радиус/анимация добавлены как токен и отражены в обоих клиентах.

## Анти-паттерны

- Градиентные кнопки «как в CRM», кислотные тени, неон везде.
- Стеклянные карточки поверх карты без контраста.
- Шрифт меньше 12 px ради «воздуха».
- Пять акцентных цветов в одном блоке.
- Иконки-эмодзи вместо векторных там, где нужна точность (навигация, действия).
- Бесконечная пульсация каждого элемента — сонар уже пульсирует.
- Анимация загрузки, которая не заканчивается при ошибке.
